## 3주차: 네 페이지, 네 가지 분위기

- GitHub Pages URL: https://github.com/whdghk41/campus-hotspot

### 페이지별 스타일
- 프론트페이지: 사계절을 아우르는 부드러운 멀티 그라데이션 테마 / 적용한 class: `page-home`, CSS 속성: `background: linear-gradient(...)`와 퍼플 계열 테두리 포인트
- 중앙도서관(다솔관): 집중이 필요한 공간의 특성을 살린 진중하고 차분한 어두운 네이비/그레이 톤 / 적용한 class: `page-dasol`, CSS 속성: 어두운 배경색과 `border-top: 5px solid #4a5568`
- 잔디마당(니콜스관): 학교 안의 싱그러운 자연을 느끼게 해주는 안정감 있는 딥 그린 랜드마크 톤 / 적용한 class: `page-nichols`, CSS 속성: 연두빛 배경과 초록색 포인트 컬러
- 학관 아지트(매머드커피): 활기차고 시원한 느낌을 주는 청량한 하늘빛 블루 포인트 테마 / 적용한 class: `page-mammoth`, CSS 속성: 하늘색 그라데이션 배경과 파란색 계열 포인트

### 모바일 스타일
- 적용한 @media 조건: `@media (max-width: 600px)` (화면 너비가 600픽셀 이하인 스마트폰 화면 기준)
- 모바일에서 특별히 바뀌는 부분과 이유:
  - 데스크톱에서는 숨겨져 있던 '처음으로' 버튼이 모바일 상단에 나타나도록 변경 (작은 화면에서 메인 페이지로 쉽게 돌아갈 수 있도록 함)
  - 하단 이동 버튼(`.action`)과 상단 메뉴(`nav`)를 세로 방향으로 정렬하고 가로 폭을 100%로 꽉 채움 (스마트폰 화면에서 손가락으로 터치하기 편하게 만들기 위함)
  - 전체적인 안팎 여백과 제목 크기를 줄임 (좁은 화면에서 스크롤이 너무 길어지지 않고 한눈에 들어오게 하기 위함)
- 휴대전화에서 네 페이지를 확인한 결과: 스마트폰에서 레이아웃이 깨지지 않고, 버튼들이 손가락으로 누르기 좋은 크기로 알맞게 배치되어 정상적으로 작동함.
