# 3주차 실습 과제: 네 페이지, 네 가지 분위기

## 프로젝트 소개
- 성심교정에서 아끼는 장소 세 곳(다솔관, 매머드커피, 니콜스관)을 소개하는 1단 중앙 레이아웃 기반의 반응형 웹페이지 프로젝트입니다.
- HTML5 구조 태그(`header`, `nav`, `main`, `section`, `article`, `footer`)를 사용하여 코드의 의미와 가독성을 높였습니다.
- 단 하나의 외부 공통 CSS 파일(`styles.css`)을 연동하여 일관성을 유지하면서도, 바디 클래스(`page-home`, `page-dasol`, `page-mammoth`, `page-nichols`)를 활용해 각 페이지마다 사계절, 다크 네이비, 여름 하늘, 싱그러운 그린 톤의 네 가지 고유한 시각적 분위기를 구현했습니다.
- 모바일 화면에서도 레이아웃과 여백이 유연하게 조절되도록 `@media` 반응형 디자인을 적용했습니다.

## 파일 구성
- `index.html`: 사계절 파스텔 톤의 메인 프론트페이지 (장소 카드 3개 목록 제공)
- `dasol.html`: 진중한 다크 네이비 톤의 다솔관 상세 페이지
- `mammoth.html`: 청량한 여름 하늘 톤의 매머드커피 상세 페이지
- `nichols.html`: 싱그러운 포레스트 그린 톤의 니콜스관 상세 페이지
- `styles.css`: 공통 레이아웃, 네 가지 페이지별 분위기 테마, 이미지 최적화 및 모바일 미디어 쿼리가 정의된 스타일 파일
- `images/`: 장소별 사진 파일 저장 폴더
## 3주차: 네 페이지, 네 가지 분위기

- GitHub Pages URL: https://whdghk41.github.io/campus-hotspot/

### 페이지별 스타일
- 홈 (index.html): 사계절을 아우르는 부드러운 파스텔 그라데이션 / 적용 class: `page-home`, 그라데이션 background 및 `.place-card` 호버 효과 적용
- 다솔관 (dasol.html): 진중하고 차분한 학업 공간을 위한 어두운 네이비 다크 톤 / 적용 class: `page-dasol`, 배경색 `#1a202c` 및 본문 상자 어두운 톤 조정
- 매머드커피 (mammoth.html): 청량한 여름 하늘을 연상시키는 아쿠아 블루 및 레몬 옐로우 톤 / 적용 class: `page-mammoth`, 상단 블루 포인트 테두리와 그라데이션 타이틀 적용
- 니콜스관 (nichols.html): 싱그러운 포레스트 그린 톤의 랜드마크 분위기 / 적용 class: `page-nichols`, 싱그러운 연두빛 배경과 딥 그린 포인트 테두리 적용

### 모바일 스타일
- 적용된 @media 조건: max-width: 600px
- 모바일에서 바뀌는 부분과 이유: 화면이 좁아질 때 가독성과 터치 편의성을 위해 메인 페이지 네비게이션 메뉴를 세로 방향(`flex-direction: column`)으로 바꾸고, 절대 위치였던 '처음으로' 버튼을 일반 흐름으로 변경해 여백이 찌그러지지 않도록 조정했습니다.
- 휴대폰 화면으로 확인한 결과: 크롬 개발자 도구의 모바일 미리보기(Device Toggle)로 확인했을 때 텍스트 크기와 버튼 간격이 알맞게 정돈되어 출력됩니다.
